# ロードマップ — MHシミュレーター 全体タスクと進捗

> **進捗管理はこの文書が唯一の場所。** タスクを完了・追加・変更したら必ずここを更新する。

## 何に沿って進めるか(文書の役割分担)

| 知りたいこと | 見る文書 |
|---|---|
| 全体の流れ・今どこか | **本書**(ロードマップ.md) |
| なぜ作るか・スコープ・やらないこと | プロダクト企画.md |
| 機能の振る舞い・データモデル・性能予算 | 仕様.md |
| 画面の構成・文言・状態・ViewModel | 画面設計.md(実装タスク詳細は§7) |
| 見た目の規約(色・字・形・コンポーネント) | DESIGN.md |
| 環境・データ取得元・注意点・現状サマリ | 引き継ぎ.md |
| 判断の記録 | 決定ログ(ユーザーのObsidian vault。原本) |

進め方の基本ルール:

1. タスクの完了条件 = 実装+テスト/動作確認+コミット+**本書の更新**
2. 仕様変更級の判断は勝手にせずユーザー確認→該当文書を先に改訂→実装(DESIGN.md §10と同じ手続き)
3. ユーザーが手動でやったほうが速いタスク(Xcode GUI操作・アカウント作成類)は手順書を提示して依頼する
