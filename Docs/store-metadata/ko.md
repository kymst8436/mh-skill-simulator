# Korean (ko) — MHWilds 스킬 시뮬레이터

## App Name (16/30)
MHWilds 스킬 시뮬레이터

## Subtitle (28/30)
조건에 맞는 장비 검색, 호석은 카메라로 간편 관리

## Promotional Text (125/170)
원하는 스킬만 고르면 최적의 장비 조합을 검색. 결과가 0건이어도 '이 호석이 있으면 조합 가능'까지 알려 드립니다. 호석은 카메라로 찍어 빠르게 등록. 완전 오프라인이라 사냥 틈틈이 바로 쓸 수 있는 스킬 시뮬레이터입니다.

## Description (897/4000)
원하는 스킬만 고르세요. 조합이 안 되면, 노려야 할 호석까지 알려 드립니다.

MHWilds 스킬 시뮬레이터는 몬스터 헌터 와일즈를 위한 장비 검색 앱(스킬 시뮬레이터)입니다.

◆ 스킬만 고르면 되는 장비 검색
발동시키고 싶은 스킬과 레벨을 고르기만 하면 방어구·장식품·호석의 최적 조합을 빠르게 검색합니다. 무기 슬롯 지정과 아티어 무기의 자유로운 설정도 지원합니다. 결과 목록에서는 방어력과 빈 슬롯을 비교할 수 있고, '이 스킬도 더 넣을 수 있다'는 추가 스킬 후보도 한 번의 탭으로 확인할 수 있습니다.

◆ 0건으로 끝내지 않는 '호석 역추적'
조건에 맞는 장비가 없을 때, 보통의 시뮬레이터는 거기서 막다른 길입니다. 이 앱은 부족한 만큼을 역산해, 추첨으로 얻을 수 있는 감정 호석 중에서 '이 호석이 있으면 조합 가능'을 제시합니다. 존재할 수 없는 호석은 처음부터 후보에 올리지 않습니다. 다음에 노릴 호석이 명확해지니, 파밍 의욕이 달라집니다.

◆ 호석은 카메라로 한 번에 등록
소지한 호석은 TV나 모니터의 게임 화면에 휴대폰 카메라를 비추기만 하면 자동으로 읽어 들여 등록됩니다. 직접 입력할 때도 추첨 규칙상 나올 수 있는 조합만 후보로 좁혀 주므로, 빠르고 정확하게 등록할 수 있습니다.

◆ 마이 세트와 위시리스트
마음에 드는 장비 세트는 마이 세트에 저장하세요. 역추적으로 찾은 '노릴 호석'은 위시리스트에 기록할 수 있고, 입수해서 등록하면 자동으로 목록에서 사라집니다.

◆ 완전 오프라인
모든 데이터가 앱에 내장되어 있습니다. 통신이 필요 없어 로비에서도, 잠자리에서도 바로 쓸 수 있습니다.

◆ 요금 안내
모든 기능을 무료로 이용할 수 있습니다(광고 표시 있음). Pro 버전으로 업그레이드하면 광고가 표시되지 않고, 마이 세트 저장 개수 제한이 없어집니다.
