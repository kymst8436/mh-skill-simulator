## Description (726/4000)
欲しいスキルを選ぶだけ。組めなければ、狙うべき護石まで調べます。
MHWildsスキルシミュレーターは、モンスターハンターワイルズ向けの装備検索アプリ(スキルシミュレーター)です。

◆ スキルを選ぶだけの装備検索
発動させたいスキルとレベルを選ぶだけで、防具・装飾品・護石の最適な組み合わせを高速検索。武器スロットの指定や、アーティア武器の自由な設定にも対応。結果一覧では防御力や空きスロットを比較でき、「あとこのスキルも積める」追加スキル候補もワンタップで確認できます。

◆ 0件で終わらせない「護石の逆引き」
条件に合う装備が見つからないとき、普通のシミュレーターはそこで行き止まり。本アプリは不足分を逆算し、抽選で入手し得る鑑定護石の中から「この護石があれば組める」を提示します。存在し得ない護石は最初から候補に出しません。次に狙うべき護石が明確になり、周回のモチベーションが変わります。

◆ 護石はカメラで一気に登録
所持護石は、ゲーム画面にカメラをかざすだけで読み取って登録できます。手入力の場合も、抽選規則上あり得る組み合わせだけに候補が絞り込まれるため、速く・間違えずに登録できます。

◆ マイセットとウィッシュリスト
気に入った装備セットはマイセットに保存。逆引きで見つけた「狙う護石」はウィッシュリストに記録でき、入手して登録すると自動でリストから外れます。

◆ 完全オフライン
データはすべてアプリに同梱。通信不要で、ロビーでもベッドの中でもすぐ使えます。

◆ 料金について
すべての機能を無料でお使いいただけます(広告表示あり)。Pro版にアップグレードすると、広告が非表示になり、マイセットの保存上限がなくなります。
