## Description (2007/4000)
Choisissez vos talents, l'app s'occupe du reste. Et si aucun équipement n'est possible, elle vous dit quel talisman viser.

MHWilds Skill Simulator est une application de recherche d'équipement (simulateur de talents) pour Monster Hunter Wilds.

◆ Une recherche d'équipement en quelques touches
Sélectionnez les talents et niveaux souhaités : l'app trouve en un instant la meilleure combinaison d'armure, de joyaux et de talisman. Vous pouvez préciser les emplacements de l'arme ou configurer librement une arme Artian. Dans les résultats, comparez la défense et les emplacements libres, et affichez d'une touche les talents supplémentaires que chaque set peut encore accueillir.

◆ La recherche inversée de talismans : fini les impasses
Quand aucun équipement ne correspond, un simulateur classique s'arrête là. Pas celui-ci : il calcule ce qui manque et vous propose, parmi les talismans réellement obtenables au tirage, ceux qui rendraient votre build possible. Les talismans qui ne peuvent pas exister n'apparaissent jamais dans les suggestions. Vous savez exactement quel talisman viser — et vos sessions de farm retrouvent un objectif.

◆ Enregistrez vos talismans avec l'appareil photo
Pointez simplement l'appareil photo vers votre écran de jeu (TV ou moniteur) : l'app lit vos talismans et les enregistre. En saisie manuelle, seules les combinaisons possibles selon les règles de tirage sont proposées : c'est rapide et sans erreur.

◆ Mes sets et liste de souhaits
Gardez vos équipements favoris dans Mes sets. Les talismans à viser trouvés par la recherche inversée se rangent dans la liste de souhaits — et en sont retirés automatiquement dès que vous les obtenez et les enregistrez.

◆ 100 % hors ligne
Toutes les données sont incluses dans l'app. Aucune connexion requise : utilisez-la dans le lobby, dans le canapé ou sous la couette.

◆ Tarifs
Toutes les fonctionnalités sont gratuites (avec publicités). La version Pro supprime les publicités et lève la limite d'enregistrement de Mes sets.
