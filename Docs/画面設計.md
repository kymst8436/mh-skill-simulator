# 画面設計 — MHシミュレーター

## 1. この文書の位置づけ

- 対象プロダクト: MHシミュレーター(MH Simulator)
- 元になる仕様: `Docs/仕様.md`(2026-08-23改訂版)
- 対象スタック: iOS 17+ / SwiftUI / MVVM(`@Observable` ViewModel)/ iPhone縦固定
- コアロジック: `app/MHSimulatorCore/`(実装済み。`MasterDatabase` / `SearchEngine` / `CharmOracle` / `CharmRules` / `ResultValidator`)
- UI部品: SwiftUI標準構造(NavigationStack / TabView / sheet / confirmationDialog)+`Docs/DESIGN.md` の共通コンポーネント(MHCard / MHPrimaryButton / SkillChip / RarityBadge 等)。見た目は「狩猟ダーク・ミニマル」規約(DESIGN.md、2026-08-24決定)に従う
- 広告: バナー広告(SDK選定は未確定事項1)。表示位置は本書で確定する

余白・フォントはSwiftUIの既定(システムフォント+Dynamic Type)に従う。この文書では**画面の構成・文言・状態・ViewModelの形だけ**を確定し、色・余白の再定義はしない。

### 命名規則(iOS版)

画面名 `SearchCondition` の場合:

| 項目 | 値 |
|---|---|
| View | `app/MHSimulator/MHSimulator/Views/SearchConditionView.swift` |
| ViewModel | `app/MHSimulator/MHSimulator/ViewModels/SearchConditionViewModel.swift` |
| Navigation | タブ内 `NavigationStack` の `Route.searchCondition`(enum case) |

シート表示の画面も同じ規則。ダイアログはSwiftUIの `confirmationDialog` / `alert` で実装し、独立Viewを作らない。

### 広告非表示(リワード報酬。2026-08-29追加)

- 導線: **検索条件・マイセット一覧・護石一覧・ツール一覧の上部ツールバー左上**に自作アイコン(「AD」バッジに斜線)のボタンを配置。タップでsheet表示
- sheet「広告の非表示」: 説明文「リワード広告を再生することで8時間の間全ての広告が非表示となります。」+[再生して全ての広告を非表示]ボタン(MHPrimaryButton)。非表示期間中は残り時間(「残り◯時間◯分」)を表示する
- 報酬: リワード広告(報酬「Reward」×1)の視聴完了で**8時間**の全広告非表示。**3回分までスタック可能で、上限は現在時刻から24時間**。上限到達時はボタンを無効化
- 非表示期間中は**全画面の広告(バナー・ネイティブ・インタースティシャル)を表示せず、ロード自体も行わない**。リワード広告のみsheetからロード・再生できる(スタック用)
- 期限はUserDefaultsで永続化。期限到来でアプリ再起動なしに広告表示へ自動復帰する
- 広告ユニット: `ca-app-pub-4797364772307900/3695939059`(DEBUGビルドはGoogleテストユニットに自動切替)
- 実装: `AdFreeCenter`・`RewardedAdController` / `AdExperience.swift`、`AdFreeSheetView.swift`

## 3. 画面遷移

```text
[起動]
  ├→ bundled.db読込失敗 → マスタ読込失敗(全画面・終端)
  └→ TabView
       ├→ [検索タブ] SearchCondition
       │     ├→ (sheet) SkillPicker ─選択→ 閉じて条件リストに反映
       │     ├→ (push) WeaponSelect ─選択/解除→ 戻る
       │     └→ [検索] → (push) SearchResults(引数: SearchCondition, Weapon?)
       │            ├→ 1件以上 → 行タップ → (push) EquipmentDetail(引数: EquipmentSet)
       │            │      └→ [保存] → (alert) マイセット保存 → SavedSetへ登録 ※2026-08-29追加
       │            ├→ 1件以上 → [追加できるスキルを探す] → (sheet) AdditionalSkills
       │            │      └→ 行タップ → 閉じて条件に追加+自動再検索(条件画面にも反映)※Phase 5.5
       │            └→ 0件 → 同画面内に逆引き結果を表示(遷移なし)
       │                   └→ 候補行タップ → (sheet) CharmEntry(引数: 提案護石のプリセット)※Phase 4
       ├→ [マイセットタブ] MySetList ※2026-08-29追加
       │     └→ 行タップ → (push) EquipmentDetail(引数: SavedEquipmentSet。保存ボタンなし)
       ├→ [護石タブ] CharmList
       │     ├→ [追加] → (sheet) CharmEntry(引数: なし=新規)
       │     └→ 行タップ → (sheet) CharmEntry(引数: OwnedCharm=編集)
       ├→ [ツールタブ] ToolList ※2026-09-04追加
       │     └→ 行タップ → (push) EquipmentCompare(マイセット選択)
       │            └→ 行タップ(ベース確定)→ (push) EquipmentCompareResult(比較画面)
       │                   └→ [＋比較する装備構成を選択]/列見出し → (sheet) マイセット選択 ─選択→ 閉じて列に反映
       └→ [情報タブ] Info
             └→ (push) Credits
```

### 遷移の規則

- タブごとに独立した `NavigationStack` を持つ。タブ切替で各スタックの状態は保持する
- push遷移は `NavigationStack` の `path`(`[Route]`)経由。Viewから直接 `NavigationLink(destination:)` で別Viewを生成しない(引数はRoute enumのassociated valueで渡す)
- 入力を伴う画面(スキル選択・護石入力)はsheet表示。sheetのスワイプ閉じは「キャンセル」と同義(護石入力で未保存変更があれば入力破棄確認を出す)
- 検索実行中に画面を離れた場合(タブ切替)は検索をキャンセルし、戻ったときは条件編集状態(仕様3.1)

## 4. 画面ごとの詳細

### 4.1 検索条件(Route: `searchCondition`)

#### 目的

欲しいスキルと目標レベルを組み、検索を実行する。アプリの起点となる画面。

#### 採用パターン

Data Entry(モバイル適用)— 条件リストを組み立てて実行する入力画面だから。

#### 領域構成

```text
┌──────────────────────────────┐
│ 検索条件              [⚙︎(!)] │ ナビゲーションバー(歯車=検索設定。設定ありで赤バッジ)
├──────────────────────────────┤
│ 武器                          │ セクション
│  スラッシュアックス「暁光の…」 │ ← 未選択時「武器を選択(任意)」
├──────────────────────────────┤
│ スキル条件        [+ 追加]    │ セクション
│  攻撃         Lv3  [- +] ⊖   │ 行: スキル名+レベルStepper+削除
│  見切り       Lv2  [- +] ⊖   │
│  (空: 「スキルを追加して…」)  │
├──────────────────────────────┤
│        [ 検索する ]           │ 主ボタン(条件0件で無効)
├──────────────────────────────┤
│ [広告バナー]                  │
└──────────────────────────────┘
```

#### 構成要素

| # | 要素 | 種類 | ラベル/文言 | 必須 | 初期値 | 入力制約・振る舞い |
|---|---|---|---|---|---|---|
| 1 | 検索設定 | MHToolbarIconButton(歯車) | gearshape | - | - | `searchSettings` sheetを開く。固定・除外が1件でも設定されていると右上に赤い「!」バッジ(mhDestructive)を表示(2026-08-24改訂) |
| 1b | リセット | MHSectionHeaderのアクション | リセット(13pt・小) | - | - | 武器セクション見出しの右端。条件スキル全削除+武器選択解除。確認なしで即実行(2026-08-24改訂: ツールバーから移動。固定・除外設定は対象外) |
| 2 | 武器行 | NavigationLink行 | 選択中の武器名(種別+名前)/未選択時「武器を選択(任意)」 | - | 前回選択(AppState.selectedWeaponId) | タップで `weaponSelect` へpush |
| 3 | スキル追加 | Button | + 追加 | - | - | `skillPicker` をsheet表示 |
| 4 | 条件スキル行 | List行 | スキル名+「Lv<n>」 | - | 追加時は最大レベル(2026-08-23決定) | Stepperで1〜maxLevelを増減。スワイプ削除可、⊖タップでも削除。長押しメニュー「スキル詳細」でスキル詳細sheet(4.14)を開く(2026-08-29追加) |
| 5 | 検索する | Button(prominent) | 検索する | - | - | 条件スキル0件で無効。タップで `searchResults` へpush(検索は結果画面側で実行) |
| 6 | 広告バナー | AdBannerView | - | - | - | §2の配置規則に従う |

#### ViewModel

`app/MHSimulator/MHSimulator/ViewModels/SearchConditionViewModel.swift`

| メンバー | 種別 | 型 | 役割 |
|---|---|---|---|
| `conditions` | プロパティ | `[ConditionRow]`(skillId・名前・level・maxLevel) | 条件スキルリストの表示元。追加順 |
| `selectedWeapon` | プロパティ | `Weapon?` | 選択中の武器。`nil` は未選択 |
| `canSearch` | 算出プロパティ | `Bool` | `!conditions.isEmpty` |
| `addSkill(_:)` | メソッド | `(Skill) -> Void` | スキル選択sheetからの追加。既存スキルなら行を最大レベルに更新(重複行を作らない=仕様3.1の後勝ち統合) |
| `removeSkill(_:)` | メソッド | `(SkillId) -> Void` | 条件行の削除 |
| `setLevel(_:_:)` | メソッド | `(SkillId, Int) -> Void` | Stepperの反映。1〜maxLevelにクランプ |
| `reset()` | メソッド | `() -> Void` | 条件全削除+武器解除 |
| `makeSearchCondition()` | メソッド | `() -> SearchCondition` | Core APIの `SearchCondition(requiredSkills:)` を構築 |

#### 状態

| 状態 | 条件 | 表示 | 操作可否 |
|---|---|---|---|
| 初期 | 起動直後 | AppStateから前回条件・前回武器を復元して表示 | 全操作可 |
| 読み込み中 | (なし) | マスタは起動時に読込済みのため本画面に読み込み中はない | - |
| 正常 | 条件1件以上 | 条件リスト+有効な検索ボタン | 全操作可 |
| 空 | 条件0件 | スキル条件セクションに「スキルを追加して検索条件を作成してください」 | 検索無効。追加・武器選択・検索設定は可 |
| エラー | (なし) | 本画面でのエラーはない(検索エラーは結果画面) | - |
| 実行中 | (なし) | 検索実行は結果画面側 | - |

#### バリデーション

| 対象 | 条件 | メッセージ | 表示位置 | 検証タイミング |
|---|---|---|---|---|
| 条件スキル | 0件 | (メッセージなし。検索ボタン無効+空状態文言で示す) | - | 常時 |
| レベル | 範囲外 | (発生しない。Stepperで構造的に防止) | - | - |

#### 遷移

- 入口: 起動直後(検索タブのルート)
- 出口: [検索する] → `searchResults`(引数: `SearchCondition` と `Weapon?`)/ 武器行 → `weaponSelect` / [+追加] → `skillPicker`(sheet)
- 離脱時: 条件は都度保存されるため確認なし

- なし

- `app/MHSimulator/MHSimulator/Views/SearchConditionView.swift`

#### 規約から外れる点

- 2列レイアウト(左右比較)は既存画面にない。列幅は等分・列間に`mhHairlineFaint`の縦線。数値は右寄せではなく列内で左揃え(見出しと同じ基準線)
- 状態行はラベル+補助行の2段(行高最小56pt)
- 数値TextFieldを使う(既存画面はStepperのみ)。MHCard内の行に右寄せ・下線なしで揃える

#### 長文言語の確認点(CLAUDE.md ローカライズ3)

- 状態行のラベル(スキル名+「発動中」バッジ: de「Aktiv」/ es「Activa」/ fr「Actif」/ pt-BR「Ativo」/ ko「발동 중」/ en「Active」)は全幅約300ptなので1行に収まる想定。補助行「ベース Lv3 ・ 比較 Lv2」はde/frで長くなるため折り返し可
- 「<スキル名>(<条件>)」の括弧は言語別の書式キー(`%@(%@)`: 日本語・韓国語は直付け、欧文は半角スペース)で組む(2026-09-04実装)
- 装備名(de/frの防具名が長い)は2行で`lineLimit(2)`+末尾省略
- プルダウンの選択値(es「Píldora de fuerza」等)は項目名の下に2段落ちを許容
